01Practice

What a thing does
and how it reads, decided together.

/ 01

Function

Every screen and control has to earn its place. If it doesn’t make the program more useful or clearer, it goes.

  • One job per screen
  • Plain words, no jargon
  • Fewer steps to done

/ 02

Design

Type, spacing and order do the work. The look is quiet so the content can be read at a glance.

  • Hierarchy before decoration
  • Readable at arm’s length
  • Calm on low-end phones

/ 03

Engineering

Correct, quick, and careful with resources. Privacy and safety are set up at the start, not patched in later.

  • Native builds, small size
  • No needless data collection
  • Tested on real devices

House rules

  1. 01Functional design Form follows the task.
  2. 02Precision Correctness, speed, detail.
  3. 03Simplicity Hard problems, easy surface.
  4. 04Privacy Collect as little as possible.
  5. 05Safety Part of the design, not an extra.
  6. 06Restraint Polished, never loud.
  7. 07Testing ideas Try what might work better.
  8. 08For everyone Regions, devices, abilities.

03The name

Sruc स्रुच्

A sruc is the wooden ladle used to carry an offering to the fire. A simple tool with one exact task. We took the name as a working standard: carry the idea without spilling it. Give it form. Set it down where it is useful.
